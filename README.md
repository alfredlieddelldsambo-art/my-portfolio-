# Alfred Lieddell D Sambo – Portfolio

A responsive personal portfolio website made with HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository (for example, `alfred-portfolio`).
2. Upload `index.html` and the `assets` folder from this project.
3. Open the repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish your site. The URL will look like `https://YOUR-USERNAME.github.io/alfred-portfolio/`.

## Customize
Replace `assets/profile.*` with your preferred photo and keep the filename the same, or update the image path in `index.html`.
